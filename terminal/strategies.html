From simulation to the demo account

  1. Watch the Live Dashboard feeds; the model-approved feed is the same score family used by the “Model High-ROI” archetype.
  2. Size with the paper ledger (Portfolio → Paper) — positions marked to the live demo API.
  3. When a rule survives, enable demo execution in Portfolio → Settings (demo keys, stored only in your browser) and use “Demo-account buy YES” on the dashboard.
  4. Review fills, realized P&L and per-topic attribution in Portfolio → Demo account.
