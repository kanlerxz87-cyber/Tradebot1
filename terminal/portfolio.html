Kalshi demo API credentials

A tiny server-side shim must add the three KALSHI-ACCESS-* headers to the handshake. See Suggestions → WS proxy. Without it, the dashboard polls REST — fully functional, just not push-based.

Where do I get demo API keys?

  1. Create/log in to the demo environment at demo.kalshi.com ↗.
  2. Profile → API Keys → Create New API Key (Ed25519 default; RSA also supported). Save the private PEM — it's shown once.
  3. Paste the key ID and PEM above. Production keys do not work on demo endpoints.

Official instructions: docs.kalshi.com → API Keys ↗
