How resolution works on Kalshi

Kalshi event contracts pay $1.00 for YES (correct) and $0.00 for NO. Each market carries written rules naming a settlement source; when the event occurs (or doesn't), the exchange settles the contract and the result field becomes yes or no. This page reads exactly those fields from GET /events?status=settled / GET /markets in the demo environment. Where a value can't be confirmed, it shows “—” and is flagged on the Flagged for Review page — never invented.

Kalshi market rules and settlement sources are viewable on each contract's rules page (link “Kalshi ↗” per row). Demo settlements use the same mechanics with mock funds. Official API reference: docs.kalshi.com ↗
