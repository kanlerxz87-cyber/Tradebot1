    About executing trades

    Live order placement needs the same signing, plus the V2 order endpoint. The signing job exists in this repository (tools/demo-account.mjs), and order placement is deliberately not wired up: nothing in this repository sends an order, ever. The simulated strategies are a local test harness. If order execution is added later, it belongs in the same Actions job with a hard demo-only guard, and the docs name POST /portfolio/events/orders as the endpoint.
