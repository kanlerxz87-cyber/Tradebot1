Kalshi live-event dashboard & alerting system

Tracks the highest-dollar live events in five topics — gas prices, elections, culture, crypto and golf — and alerts on any contract move of at least $0.10 in either direction. Two alert feeds, a strategy simulator, and a verification register where each fact carries the official source it came from.

Data provenance for this build: captured-replay. The live engine could not reach Kalshi from the build environment, so this snapshot was built from real captured API payloads plus a scripted price path used to exercise the alert logic. Every market, strike and quote that is copied is labelled as captured; derivations are flagged. The live version of this dashboard runs as a small Python service (see the repository README) and uses the same code paths.
