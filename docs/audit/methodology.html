How to reproduce this page

Every page below was fetched from docs.kalshi.com (or the fee-schedule PDF) with a page-fetch tool on 2026-11-22 and quoted verbatim. Shell curl from this sandbox cannot reach kalshi hosts (TLS reset), which is the limitation earlier sessions reported; the page-fetch tool can, so these pages were read directly rather than cited from memory.

Command line

python3 audit/verify.py          # re-run every check, rewrite the data file
python3 audit/build_site.py      # regenerate these pages
python3 audit/check_site.py      # gates: source on every row, no broken links, pages current
python3 -m pytest -q             # the repository's Python suite, including the audit regressions
node --test tests/*.test.mjs     # the repository's JavaScript suite

Rules this page follows

  1. A verdict needs a statement. If no official page says it, the row does not exist; the item goes to Flagged for review instead.
  2. A quote, not a paraphrase. Every source row carries the excerpt it rests on.
  3. A line, not an impression. Evidence is stored as a snippet and the printed line number is resolved at build time.
  4. A check, not an assertion. verify.py executes the code and compares the result with what the page claims; a mismatch fails the build.
  5. Nothing inferred. An absent value stays absent. Where a number could not be observed - an authenticated balance, an executed fill, a live socket - no number is printed.
  6. Two vocabularies are not a contradiction. Where the documentation and an earlier flag disagree, both are quoted and the point is settled, not repeated.
