VF-05 Orderbook Responses
A **YES BID** at price X is equivalent to a **NO ASK** at price ($1.00 - X)
 The order book returns bids only, and the ask on one side is the complement of the best bid on the other side.
docs.kalshi.com/getting_started/orderbook_responses
VF-06 Orderbook Responses
Arrays are sorted by price in **ascending order** [..] The **highest** bid (best bid) is the **last** element in each array
 Levels are ascending by price, so the best bid is the last element of each array.
docs.kalshi.com/getting_started/orderbook_responses
VF-07 Orderbook Responses
A market with no resting orders returns empty `yes_dollars` and `no_dollars` arrays. So does a ticker that does not match any market: the endpoint returns `200` with empty arrays rather than `404`
 An empty book and an unknown ticker both return 200 with empty arrays, not 404.
docs.kalshi.com/getting_started/orderbook_responses
VF-08 Orderbook Responses
The orderbook response is wrapped in an `orderbook_fp` object containing two arrays of bids: `yes_dollars` for YES positions and `no_dollars` for NO positions. Each bid is a two-element string array: `[price_dollars, count_fp]`.
 The order book is wrapped in orderbook_fp with yes_dollars and no_dollars string pairs [price, count].
docs.kalshi.com/getting_started/orderbook_responses
VF-09 Fixed-Point Representation

 Prices are dollar strings with a _dollars suffix (up to 4 dp) and quantities are _fp strings (2 dp).
