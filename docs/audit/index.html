How the audit was done

Read, then quote

Each official page was fetched on 2026-11-22 and a short excerpt stored with its URL in audit/facts.json. The published page shows the excerpt next to the claim, so a reader can disagree with the reading rather than with a summary.

Check the code, not the comment

audit/verify.py runs the JavaScript with node and the Python with the repository's own modules. A finding marked fixed must pass its check; a finding marked open must still reproduce. If either changes, the build fails and the page cannot publish a stale verdict.

Only what can be shown

No credential was available, so nothing here claims an authenticated read, an executed order, a live WebSocket session or a browser CORS result. Those remain on the flagged page where earlier sessions left them.
