Known gaps in this build

  • The static site shows a snapshot. A browser page cannot hold a Kalshi private key, so live alerting and order execution run in the Python service, not here.
  • The snapshot was produced in an environment with no route to Kalshi. Market, strike and quote values are real captured API responses; the price paths used to demonstrate alerts are scripted and labelled captured-replay.
  • Per-series fee multipliers and the fee rebate accumulator are not modelled in simulation.
