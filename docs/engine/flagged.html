Known gaps in this build

  • Authenticated Kalshi demo orders and WebSocket handshakes require RSA-PSS / Ed25519 KALSHI-ACCESS-* headers that browsers cannot attach safely on static hosting; public GET polling runs live on live.html, while authenticated execution runs in the local Python service (uvicorn app.main:app).
  • Baseline offline tables use real captured API responses plus deterministic price paths labelled captured-replay when offline.
  • 31 Non-Standard Fee rows from Kalshi's July 7, 2026 PDF and explicit API fee_multiplier values are applied; interleaved PDF rows from KXMVE onward and the micro-cent fee rebate accumulator remain unmodelled.
