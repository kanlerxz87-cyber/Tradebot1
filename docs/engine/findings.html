Executive summary

What this project does, what was verified against Kalshi's own material, and the findings that a trader or reviewer needs before trusting anything on this site.

1. Scope

The dashboard tracks live Kalshi events in five topics only — gas prices, elections, culture, crypto and golf — and raises an alert whenever a contract's price moves by $0.10 or more in either direction. It keeps tracking each event until Kalshi determines the outcome, records whether it resolved YES or NO, and runs six simulated strategies with their own portfolios so the strategies can be compared by category.

2. What was verified

32 of 39 recorded facts are backed by an official Kalshi page or an official Kalshi API response. The full list, each with a link, is on the Verification page.

  • Endpoints. Demo REST is https://external-api.demo.kalshi.co/trade-api/v2 and production is https://external-api.kalshi.com/trade-api/v2; the WebSocket hosts are wss://external-api-ws.demo.kalshi.co/trade-api/ws/v2 and wss://external-api-ws.kalshi.com/trade-api/ws/v2. [source] [source]
  • Orderbook shape. The book returns bids only; a YES bid at X equals a NO ask at 1−X; arrays are ascending, so the best bid is the last element. [source]
  • Fees. Taker fee is roundup(0.07 × C × P × (1−P)) and maker fee is roundup(0.0175 × C × P × (1−P)); there is no settlement fee. This project's fee code reproduces all 42 values in Kalshi's published fee table exactly. [source]
  • Taxonomy. Kalshi publishes 14 categories; Golf is a tag under Sports, and Oil & Gas is a tag under Commodities. [source]
  • Resolution. A determined market carries result (yes/no) and settlement_value_dollars; the lifecycle WebSocket carries the same fields. [source]

3. Findings that change how to read this dashboard

Finding 1 — There is no "Gas" or "Culture" category on Kalshi

Kalshi's published taxonomy has no Gas category and no Culture category. The five topics on this dashboard are therefore views built from Kalshi's own fields, not categories Kalshi defines. Gas is matched from the documented KXAAAGASM series (Kalshi's own fee schedule calls it "US gas price"), the Oil & Gas tag, and gas keywords. Culture is Kalshi's Entertainment and Mentions categories. [source] [source] Every row states which rule placed it in its topic.

Finding 2 — Kalshi's gas markets are filed under Economics

The live KXAAAGASM-26NOV30 event returns category: "Economics", not Commodities. A dashboard that matched gas by category alone would miss every gas market. [source]

Finding 3 — The category query parameter does not filter

A request for /events?category=Crypto returned a World event and an Elections event; a request for category=Entertainment returned a Science and Technology event. The engine therefore fetches open events and filters on the published fields itself. [source]

Finding 4 — A one-sided book looks like a 100-cent collapse

Demo markets routinely publish no_bid_dollars = 0.0000 beside yes_ask_dollars = 1.0000. Naively watching the ask would fire a $0.10 alert on every empty book, in both directions. This dashboard computes the mid of a two-sided book, falls back to the last trade on a one-sided or crossed book, and labels the alert quote-only when there was no trade behind the move. [source] [source]

Finding 5 — Demo prices are placeholders, and they disagree with production

At capture, the demo gas market KXAAAGASM-26NOV30-3.00 quoted 99c for "above $3.00", while Kalshi's public production page for the same series quoted "Above 3.50" at 47c with strikes at 3.45 / 3.50 / 3.55. The demo board also carries 2099 expiries and custom_strike of {"demo strike": "demo strike"}. Kalshi documents that demo prices may not reflect real markets, and this is what that looks like in practice. [source]

Finding 6 — Documented values that the live API contradicts

GET /markets documents status values unopened | open | closed | settled, but live responses use active for open markets and finalized for settled ones. [source] Multivariate KXMVE… combo markets also dominate the open-market list; 24 of the first 60 open markets were combos that bundle unrelated sports legs into one ticker, so they are excluded from single-topic boards. [source]

4. What could not be verified

  • A signed request against a real Kalshi account. No demo API key exists in this repository, so the signing code is unit-tested but has never authenticated. unverified
  • The WebSocket handshake. Documented and implemented, never observed live. unverified
  • Whether Kalshi sends CORS headers. No official statement found; the static site therefore does not call Kalshi from the browser. unverified

5. Irregularities affecting the numbers

  • Per-series fee multipliers are not applied. The simulator uses the general 0.07 / 0.0175 rates; series the schedule marks 0 (e.g. KXBTCY) would be overcharged in simulation. flagged
  • The fee rebate accumulator is not modelled. Simulated P&L can differ from the exchange by fractions of a cent per fill. flagged
  • The demo golf event had already passed its stated expiry while still listing as active. Closing times are shown rather than assumed. flagged

All of these are published with source links on Flagged for review.

6. How to use it

  1. Pick a topic. Each topic page lists every captured entry in one table, with the price, both sides of the book, volume, open interest and a source link.
  2. Watch the two alert feeds: all events (every ≥$0.10 move) and high ROI (the same moves, filtered by a trade-quality score).
  3. Compare strategies on the portfolio view: each strategy is a distinct trade category with its own starting balance, so returns are comparable.
  4. Check Flagged for review before relying on any specific figure.
