What “partial” means here

  • #12 demo account — the integration is written, tested for request shape and dormant. It cannot report numbers until a human creates the demo account and its API key. Inventing a balance would be the only alternative, and that is not acceptable.
  • #18 news attribution — the brief asks for links that “may have caused” a jump. Every alert now shows Kalshi's own contract links plus date-restricted news searches. What it never does is assert a cause: the repository has no news source it can verify, so a search window is shown instead of a guessed headline.

Everything else is complete in this repository and reproducible with the commands on the verification page.
