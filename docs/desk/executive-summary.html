Executive summary

A Demo-only research and paper-trading desk for five Kalshi topics — gas prices, elections, culture, crypto, and golf. It is designed to record observed ≥ $0.10 swings, show time/price charts and order-book depth, track markets through final settlement, and keep simulated strategy results separate from exchange account activity. The current snapshot is unverified and market-derived values remain blank pending a successful Demo-only collection; GitHub Pages is not an always-on exchange connection.

What this build does

Kalshi documents public market-data reads separately from authenticated account requests. The scheduled collector now targets the official Demo environment and the static site consumes its timestamped snapshots; the current snapshot is unverified, so the public desk withholds market values until a successful Demo-only refresh. When populated, one feed shows observed moves of at least ten cents and another shows candidates that pass a documented heuristic. Paper strategies use a local ledger, not the Demo-account balance. The optional protected Demo order route is a separate server feature; it is disabled unless a trusted host has credentials and an explicit execution enable flag. No authenticated Demo order, fill, balance, or WebSocket session was verified for this publication.

What is delivered

Delivered

  • Dashboard — five-topic market view, swing feeds, time/price chart, order-book depth and resolution tracker. Market values are currently withheld; when populated, 24-hour dollars are estimated as contract volume × price and are not a complete exchange-wide turnover ranking.
  • Five topic pages with server-rendered tables and official source links when market rows are available.
  • Four paper strategies and a documented heuristic screen; the score is not a validated ROI forecast.
  • Paper portfolio analytics — equity, settled trades and strategy/topic breakdowns when verified inputs exist; current market-derived figures are withheld. These are simulated results, not Demo-account performance.
  • Verification log with dated official-source claims and the corresponding capture provenance.
  • Flagged for review — open limitations, source links and intentionally blank unverified account values.

Autonomy

  • GitHub Actions schedules Demo-only market-data collection and publishes timestamped snapshots; this static site is not a continuous exchange stream.
  • No account input is needed for public Demo observations or paper simulation, but the current snapshot is unverified; age and collection errors are shown instead of invented values.
  • Failures such as network errors, rate limits or unknown fields are recorded in the snapshot and disclosed on the page.
  • A separate Demo service implementation provides lower-latency collection and protected account routes; it is not part of the static Pages deployment, and its exchange connection and account execution are not verified here.

Decisions worth knowing

Demo data, execution in paper

The scheduled collector and local default use Kalshi's Demo REST API; browser and static builders reject snapshots unless the environment label and REST root match an official Demo endpoint. The previous production snapshot was removed; the current committed snapshot is explicitly unverified and blank until a successful Demo-only cycle. Flagged as F6.

Static site plus a real collector

GitHub Pages cannot poll an exchange, so the alternative is either a fake “live” label or a scheduled collector that commits what it saw. The second is real: the page always shows the snapshot's timestamp and turns amber after 30 minutes. Flagged as F10.

Nothing is estimated into a blank

No demo balance, no fee number presented as official, no causal news claim. Missing values render as “—” and the reason appears on the Flagged page. This is the single rule the whole build is organised around.

The model is deliberately boring

Six weighted components, published weights, a version string, and a disclaimer printed next to every result. It exists to reduce alert noise, not to predict. Its accuracy will be whatever the ledger measures.
