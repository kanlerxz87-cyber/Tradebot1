A source-linked technical brief for a public Kalshi demo research dashboard. The initial repository contained only a one-line README; all implementation is new and kept separate from authenticated account operations.

Verified API facts

Each row links directly to official Kalshi documentation. Values not verified are omitted from the market tables.

AreaOfficially documented factSource
EnvironmentRecommended demo REST: https://external-api.demo.kalshi.co/trade-api/v2. Supported alternate: https://demo-api.kalshi.co/trade-api/v2. Demo and production credentials are separate.Kalshi environments ↗
StreamingRecommended demo WebSocket: wss://external-api-ws.demo.kalshi.co/trade-api/ws/v2; shared alternate also supported. WebSocket handshake requires signed API-key headers even for public channels.Kalshi WebSocket quick start ↗
DiscoveryEvents can include nested markets; paginated listings use a cursor and a 200-event page limit. The standard events endpoint excludes multivariate events.Kalshi Get Events ↗
Quotes & outcomesMarket objects expose dollar-formatted YES bid, ask, last price, 24h contract volume, status and result fields. Listing prices are cached and can lag.Kalshi Get Markets ↗
DepthPublic market orderbook returns fixed-point quantities at YES and NO bid levels. It is a point-in-time read; no direct ask-side ladder is supplied.Kalshi orderbook responses ↗
HistoryCandlesticks require start/end Unix timestamps and intervals of 1, 60, or 1440 minutes; seconds on this dashboard are browser-session observations, not API candles.Kalshi candlesticks ↗
Account / executionReading account balance and submitting demo orders require signed headers; V2 event orders use /portfolio/events/orders. This public site does not request, store or use credentials.Kalshi authenticated requests ↗ · Orders ↗

Decision framework

Implementation choices, not claims made by Kalshi.

DecisionCurrent implementationEvidence / limitation
Rank activityEstimated 24h traded dollars = last YES price × 24h contract volume; sum by event and rank only the scanned subset.Input fields ↗ · derived proxy, not reported dollar turnover
Detect movesCompare successive observed last YES prices and alert if absolute delta ≥ $0.10. No baseline alert.Price field and caching ↗ · between-poll swings may be missed
Screen interestTransparent spread/volume/ask rule. Screened alerts can open one local paper YES buy at the reported ask.Quote and volume fields ↗ · heuristic only; no ROI forecast
Follow resolutionRefresh tracked market tickers and only report YES/NO when market object status is finalized with a corresponding result.Market result and tickers filter ↗
Next architecture step: Run a private server with securely stored demo API credentials for authenticated ticker/orderbook/lifecycle WebSocket subscriptions, persistent timestamped history, live order routing with limits, and portfolio fills/fees reconciliation. A static Pages site cannot securely sign a WebSocket handshake or submit account orders. See Flagged for Review for open constraints.
