Sources

Four kinds of claim appear on this site and they are kept apart. Official documentation is Kalshi's own docs. Live API observations are responses read from the demo API on the date shown, with the exact request. Primary data publishers are third parties that Kalshi's own series records name as settlement sources. Project rules are choices made for this dashboard, and they are never presented as exchange facts.
