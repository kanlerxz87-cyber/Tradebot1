## 3. Fee model, checked against Kalshi's own table

The official PDF states `fees = round up(M × 0.07 × C × P × (1 − P))` and describes the rounding
as "such that the fee + positionCost is rounded to a centicent".

| Rounding rule | Rows reproduced |
| --- | --- |
| Up to $0.0001 (the literal centicent reading) | **0 of 21** — at $0.01 the formula gives $0.0007 against a printed $0.01 |
| Up to the whole cent | **20 of 21**, in both the 1-contract and 100-contract columns |

The one row that fails is $0.01, and the PDF's text layer for that row is internally inconsistent
(its 100-contract value reads `$1.00`, which is the price column). The whole-cent rule is used, and
the discrepancy is published as **F-02** rather than special-cased. `tests/fees.test.mjs` asserts
all 20 reproducible rows in both columns and asserts that exactly one row is excluded and which.

## 7. Deviations from the brief, and why

| Brief said | This build does | Reason |
| --- | --- | --- |
| "our model likes as high ROI" | A 0–100 triage score, labelled a heuristic, with components shown | There is no evidence base for an ROI claim; calling it ROI would be false |
| "links to events and websites that may have caused a sharp jump" | Links to the market, its order book and the exchange's named settlement sources | The API returns no cause; inventing an attribution would be a hallucination |
| "execute trades" | Simulated trades only; the demo-account job reads and never writes an order | Keeps the project incapable of trading by accident; the V2 order endpoint and its fields are documented on the API page for a future, deliberate step |
| "track the portfolio performance using the kalshi demo account" | Two clearly separated things: the simulator, and the real demo-account snapshot | Conflating them would misrepresent a project choice as an account balance |
| "no manual input on my part" | Everything runs on schedules; the only manual step is adding API-key secrets, which cannot be automated safely | A secret cannot be created by the site; the page states exactly what to add and where |
